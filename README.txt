Cómo usar:
1. Descomprimir el ZIP.
2. Abrir index.html en el navegador.
3. Para cambiar textos: editar index.html.
4. Para cambiar estilos: editar styles.css.
5. Para cambiar la foto: reemplazar assets/thiago.jpg por otra imagen con el mismo nombre.
